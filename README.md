# Controle de Lote de Mel
## Descrição do Problema
Um apicultor precisa calcular o lucro final de um lote de mel considerando o peso bruto, o peso da caixa e o preço por quilo.
## Requisitos
- Calcular o peso líquido do mel
- Aplicar um desconto de 10% se o lote for maior que 20kg
- Calcular o lucro total
## Exemplo de Uso
Entrada: peso_bruto = 25.0, peso_caixa = 1.5, preco_kg = 40.0
Saída: Lucro total: R$ 954.00
